## 效果对应说明

### 效果 1：首页轮播图切换

- 所在页面：`index.html`
- 所在文件：`js/index.js`
- 注释位置：第 9-10 行
- 代码位置：第 11-61 行
- 运行结果：
  - 点击上一张、下一张按钮可以切换轮播内容
  - 点击下方圆点可以切换到对应卡片
  - 页面加载后每隔 3 秒自动轮播一次
- 实现方式：
  - `showSlide(index)` 用来切换卡片和圆点的激活状态
  - `nextSlide()` 负责计算下一张内容
  - `startAutoPlay()` 使用 `setInterval()` 实现自动播放

### 效果 2：首页统计数字递增

- 所在页面：`index.html`
- 所在文件：`js/index.js`
- 注释位置：第 64-65 行
- 代码位置：第 66-83 行
- 运行结果：
  - 页面加载后，统计区数字会从 0 逐步增长到目标值
- 实现方式：
  - 通过 `.stat-number` 获取所有数字节点
  - 读取 `data-target` 作为最终数值
  - 使用 `setInterval()` 实现数字递增
  - 达到目标值后通过 `clearInterval()` 停止计时器

### 效果 3：四季知识内容切换

- 所在页面：`pages/knowledge.html`
- 所在文件：`js/knowledge.js`
- 注释位置：第 2-3 行
- 代码位置：第 4-22 行
- 运行结果：
  - 点击春季、夏季、秋季、冬季按钮时，页面切换显示对应季节内容
- 实现方式：

  - 再给当前按钮和对应内容面板添加 `active`

### 效果 4：农业问答手风琴展开

- 所在页面：`pages/knowledge.html`
- 所在文件：`js/knowledge.js`
- 注释位置：第 24-25 行
- 代码位置：第 26-40 行
- 运行结果：
  - 点击某一项问答标题后，当前答案展开，其他答案收起
- 实现方式：
  - 获取所有 `.accordion-title`
  - 通过 `parentElement` 找到当前问答项
  - 遍历 `.accordion-item`，移除其他项的 `open` 状态
  - 使用 `classList.toggle("open")` 控制当前项展开和收起

### 效果 5：种植计划计算器

- 所在页面：`pages/practice.html`
- 所在文件：`js/practice.js`
- 注释位置：第 2-3 行
- 代码位置：第 4-56 行
- 运行结果：
  - 选择作物并输入面积后，点击生成按钮，页面会输出对应的种植安排结果
- 实现方式：
  - 使用 `cropMap` 保存不同作物的数据
  - `createPlan()` 根据作物类型和面积计算结果
  - 通过 `textContent` 将结果写入页面
  - 页面首次加载时自动执行一次，保证默认结果可见

### 效果 6：任务进度条更新

- 所在页面：`pages/practice.html`
- 所在文件：`js/practice.js`
- 注释位置：第 58-59 行
- 代码位置：第 60-88 行
- 运行结果：
  - 点击“完成下一个步骤”后，任务项会依次完成，进度条和提示文字同步更新
- 实现方式：
